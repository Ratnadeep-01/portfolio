# 🚀 Ratnadeep Kumar — Personal Portfolio & Engineering Showcase

A high-performance, dark-modern personal portfolio website engineered for **Ratnadeep Kumar** (B.Tech Computer Science & Engineering undergraduate at the **National Institute of Technology Patna**, graduating in 2028).

Designed with high-converting recruiter UI/UX, buttery-smooth GSAP and Lenis scroll mechanics, 3D tilt interactions, and factual data extracted directly from GitHub repositories.

---

## 🌟 Key Highlights & Engineering Features

- **⚡ Modern Technology Stack:** Built with **React 19**, **Vite 6**, and **Tailwind CSS**, delivering sub-second load times and 60fps animations.
- **🌀 Smooth Scrolling & Physics:** Powered by **Lenis** smooth scroll, harmonized with **GSAP & ScrollTrigger** for pinned horizontal project showcases and fluid section reveals.
- **🎯 3D Tilt & Magnetic Cursor:** Interactive 3D perspective cards on desktop, magnetic button attraction, and custom follower cursor with fine pointer detection.
- **📱 Mobile-First Responsive Design:** Seamlessly scales from iPhone/Android screens up to 4K ultra-wide monitors. Horizontal pinned track on desktop automatically adapts to an intuitive stacked card flow on mobile.
- **♿ Accessibility & Performance:** Full compliance with `prefers-reduced-motion`, semantic HTML5 tags, fast WebP image compression, and zero console errors.
- **🎨 Design System:** Dark aesthetic with subtle SVG noise texture, glowing neon gradients (electric violet `#8b5cf6` to cyan `#06b6d4`), and glassmorphism.
- **🎉 Interactive Contact Form:** Functional client-side validated message form with celebratory confetti physics (`canvas-confetti`) and 1-click clipboard email copy.

## 🛠️ Local Development Instructions

### Prerequisites
- Node.js `v18+` or `v20+` or `v22+`
- npm `v9+` or `v10+`

### Installation & Run

```bash
# Clone the repository
git clone https://github.com/Ratnadeep-01/portfolio.git
cd portfolio

# Install dependencies
npm install

# Start local development server
npm run dev
```

Visit `http://localhost:3000` (or the port specified by Vite) in your browser.

### Production Build

```bash
# Create optimized production build
npm run build

# Preview production build locally
npm run preview
```
